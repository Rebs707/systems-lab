01

CLOUD INFRASTRUCTURE · FAILURE SIMULATION

Cloud Chaos Theatre

An interactive environment for simulating cloud infrastructure failures, tracing dependency-driven service disruption and examining incident diagnosis and recovery strategies. The simulation is deterministic, and all infrastructure is simulated.

View GitHub repository ↗
02

ENTERPRISE AI SYSTEMS · INFORMATION RETRIEVAL

Enterprise Knowledge Platform

A local-first document intelligence platform built with FastAPI and SQLite. It supports validated text and Markdown ingestion, overlapping text chunking, persistent metadata and chunk storage, and deterministic keyword-based retrieval through HTTP API endpoints.

Implementation evidence: 18 automated tests, including 7 HTTP-level API integration tests.

PythonFastAPISQLiteDocument processing
View GitHub repository ↗ Read engineering case study ↗

Current boundary: Retrieval is keyword-based. The current release does not implement embeddings, vector search or an LLM.

05 / ABOUT

SL.

About Systems Lab

My work brings together an academic background in Human Resource Management and technical experience across cloud infrastructure, platform operations and artificial intelligence. This combination informs an interdisciplinary perspective on computing systems, intelligent technologies and the environments in which they are developed and used.

My research interests span Artificial Intelligence and Generative AI, Cloud Computing and Distributed Systems, and Intelligent Enterprise Systems. Across these areas, I am interested in the design, development, evaluation and operation of intelligent applications and the technical foundations that support them.

My technical interests include large language model applications, retrieval-augmented generation, agentic systems, cloud-native architectures, distributed computing, infrastructure automation and operational reliability. I am also interested in how intelligent technologies support enterprise knowledge access, decision-making and human-AI collaboration.

Systems Lab brings these interests together through technical implementations, systems exploration and the development of research directions. It provides a space to examine intelligent computing systems across their architecture, infrastructure, applications and organisational contexts.
