SYSTEMS LAB — INITIAL WEBSITE
================================

Contents
- index.html: site structure and content
- styles.css: responsive visual design
- script.js: mobile navigation and footer year

Deploy
1. Extract this folder on your computer.
2. In Cloudflare Pages, upload the CONTENTS of this folder (index.html, styles.css, script.js).
   If the upload picker supports folders, select the systems-lab folder itself.
3. Deploy the site.
4. Open the generated systems-lab.pages.dev address and check the homepage.

Before sharing publicly
- Replace hello@systemslab.example in index.html with a contact address you want to publish, or remove the contact link.
- Review every project description and update it to match the exact work and status.
- Add publication titles, dates, citations and links only when they are real and ready to share.

This is an initial static site. It does not contain fabricated degrees, publications, research results, or supervisor endorsements.
